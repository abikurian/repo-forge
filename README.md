# 🛠️ Repo Forge

A lightweight, interactive Node.js CLI tool designed to instantly scaffold boilerplate files for new software projects. Built to eliminate repetitive repository setup tasks and ensure consistent documentation standards.

## ✨ Features
- **Interactive Prompts:** Uses Inquirer to gather project metadata (Name, Author).
- **Auto-Generates Documentation:** Instantly scaffolds a standardized `README.md` with project-specific titles.
- **Pre-configured `.gitignore`:** Automatically generates a `.gitignore` tailored for Node environments.
- **Global Execution:** Can be linked globally to run in any directory on your machine.

## 🚀 Installation & Setup

1. Clone this repository:
   ```bash
   git clone [https://github.com/abikurian/repo-forge.git](https://github.com/abikurian/repo-forge.git)
2. Navigate into the directory and install dependencies:

```
cd repo-forge
npm install
```
3. Link the package globally on your local machine:
```
npm link
